# M5 Time Series Forecasting Assignments

Assignments on the [M5 Forecasting Accuracy](https://www.kaggle.com/c/m5-forecasting-accuracy) retail sales data.

| # | Notebook | Topic |
|---|---|---|
| 1 | `notebooks/01_assignment1_decomposition` | STL decomposition of store sales |
| 2 | `notebooks/02_assignment2_stationarity` | ADF/KPSS tests and differencing |
| 3 | `notebooks/03_assignment3_forecasting` | Seasonal ARIMA vs. Prophet |

## Data

The M5 CSV files are not included (too large). Download them from Kaggle into a `m5-forecasting-accuracy/` folder at the repository root.
